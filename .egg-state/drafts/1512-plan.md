# Plan: Add transient crash restart to consensus wrapper

## Summary

Add transient crash detection to the consensus wrapper's non-zero exit handler. When an agent exits with a signal-based exit code (segfault, OOM, SIGABRT) or Bun's exit code 255, classify it as transient and enter the existing restart loop with exponential backoff — instead of immediately failing. This reuses the existing recovery machinery (BRC state fetch, recovery prompts, anchor loading, confirmed-state detection) rather than building a parallel path.

**Risks / edge cases**: Agents in a crash loop are bounded by `MAX_RESTARTS` (shared with clean-exit restarts). Exit code 255 from Bun is treated as transient — worst case is one extra restart attempt if 255 was actually a permanent error. The existing test `test_nonzero_exit_does_not_restart` needs updating to assert on non-transient codes (e.g., exit 1) specifically.

## Implementation

### Phase 1: Implement

Add transient crash detection and restart-with-backoff to the consensus wrapper, reusing the existing restart loop machinery.

**Tasks**:
1. **[task-1-1]** In `orchestrator/consensus_wrapper.py`, add a shell function `is_transient_crash()` to the `_CONSENSUS_WRAPPER_TEMPLATE` that returns 0 (true) for exit codes indicating signal-based crashes: 137 (SIGKILL/OOM), 139 (SIGSEGV), 134 (SIGABRT), 136 (SIGFPE), and 255 (Bun segfault wrapper). Returns 1 (false) for all other codes. Acceptance: function correctly classifies transient vs non-transient exit codes.
2. **[task-1-2]** In `orchestrator/consensus_wrapper.py` lines 211-234, modify the non-zero exit handler: after the consensus/confirmed checks fail, call `is_transient_crash $AGENT_EXIT`. If transient, log `"Transient crash (code $AGENT_EXIT). Will restart with backoff."` and fall through to the existing restart loop (lines 292+) instead of exiting. Non-transient codes still get `"Agent failed (code $AGENT_EXIT). NOT restarting."` and exit immediately. Acceptance: segfault (139/255) reaches the restart loop; exit code 1 still exits immediately.
3. **[task-1-3]** In `orchestrator/consensus_wrapper.py`, add a `TRANSIENT_RESTART_BACKOFF_INITIAL` Python constant (default 5) and track `CRASH_BACKOFF` in the wrapper script. Insert `sleep $CRASH_BACKOFF` before each restart iteration when the previous exit was non-zero (transient crash). Double the backoff after each crash restart, capped at 30s. Clean exits (code 0) should not trigger backoff. Acceptance: backoff sleep is present for transient crash restarts; clean-exit restarts have no added delay.
4. **[task-1-4]** In `orchestrator/tests/test_consensus_wrapper.py`, add tests: (a) `test_transient_crash_triggers_restart` — behavioral test with mock agent that exits 139, verify restart occurs; (b) `test_non_transient_nonzero_exit_does_not_restart` — exit code 1 still gets NOT restarting; (c) `test_transient_crash_backoff_present` — verify backoff sleep appears in script for transient restarts; (d) `test_is_transient_crash_in_script` — verify the `is_transient_crash` function is present with correct exit codes. Update existing `test_nonzero_exit_does_not_restart` to clarify it tests non-transient codes. Acceptance: all new tests pass; all existing tests pass (with minor updates to `test_nonzero_exit_does_not_restart`).
