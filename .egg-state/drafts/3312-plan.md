## Approach

**easiest → hardest** by line count with the two structural outliers
(`gateway.py`, `pipelines.py`) at the **tail, fully in scope**. The pattern-adoption
parent that anchored the #2261 DAG is already merged (#2335), so there is no parent
slice; but because every slice edits the shared `scripts/file-size-allowlist.yaml`,
the slices are serialized into **one linear dependency chain** (`slice-1 → … →
slice-19`) per #3046 — independent branches off the shared base would collide at
integration on that file. Easiest-first ordering along the chain banks value early
given two prior attempts that never landed a slice.

Each slice follows the canonical recipe (`docs/guides/decomposition-pattern.md`,

applicable)** → `make lint` + `make test-all` green.

## Container packaging (R3 mitigation — addresses reviewer_plan NACK v1)

Nine of the 19 files are top-level modules shipped into container images by NON-recursive Dockerfile globs (`COPY orchestrator/*.py ./`, `COPY gateway/*.py ./`) or a single-file COPY (sandbox/entrypoint.py). Converting such a file to a package directory makes the glob silently stop copying it -> ModuleNotFoundError at container start, while `make lint` + `make test-all` (run on the SOURCE TREE, not the built image) stay GREEN. A broken image is a behavior change, so the fix is in scope (AC-8), folded into each affected slice — not a follow-up.

## Risks carried to reviewers

- R3 (HIGH) Container-packaging blind spot: a module shipped by a non-recursive Dockerfile glob (`COPY orchestrator/*.py`, `COPY gateway/*.py`) or a single-file COPY (sandbox entrypoint.py) silently drops out of the built image the moment its file becomes a package directory — and make lint / make test-all stay GREEN because they run on the source tree, not the image. Mitigation: same-slice Dockerfile-COPY/launch update + image-build smoke check on orchestrator 3/10/13/14/16, gateway 11/12/18, sandbox 9; packaging CONFIRM on egg_lib slices 1/17 (recursive COPY . — safe) and overseer slice-8 (no COPY today — unchanged). A broken image is a behavior change, so the fix is in scope (AC-8), not a follow-up.
- Re-export drift is the dominant risk: a missed re-export surfaces as AttributeError in a test that patches the moved symbol. Mitigation: the per-slice external-importer audit (task-N-1) + explicit per-symbol re-exports (decision-5) + make test-all gate. pipelines.py (~57 targets) is the highest-exposure slice — scheduled last, after the pattern is proven on 17 simpler files.
- _run_pipeline behavior risk: splitting a phase-transition state machine with subtle ordering. Mitigation: per-phase handlers stay private and are exercised through the existing dense seam coverage; pure-refactor discipline; scheduled last (phase-19).
- Allowlist YAML is the one shared file every slice edits. RESOLVED by the single linear dependency chain (slice-1 -> ... -> slice-19): each slice branches off its predecessor and sees the prior allowlist removal already applied, so there is no parallel-branch modify/modify collision (#3046). The section-(e) rebase recipe still applies when a slice rebases onto the advancing chain tip. (Any earlier 'independent / parallel slices' framing is SUPERSEDED by the serialized chain — slices are NOT independent branches.)
- Submodule-over-cap after extraction: a naive split leaves a submodule still over the cap. Mitigation: per-slice task to verify EVERY submodule under BOTH caps + further-split in-slice (section-(g)), never a fresh allowlist entry; outliers (phases 18-19) have explicit further-split tasks.
- Sub-package circular imports may surface latent cycles masked by the single-file shape (esp. pipelines.py / gateway.py). Mitigation: the existing routes/phases.py lazy/dual-import precedent; one consistent import style per sub-package.
- Failed-attempt history (#2817 implement-phase failure, #3111 never run, #2902 closed unmerged after main drift): main can drift under a long-running slice. Mitigation: easiest-first ordering banks value early; each slice rebases + re-runs the live audit at start; outliers land last so their longer review windows don't block the 17 simpler wins.
- entrypoint.py / orch_cli.py have script-execution entry points (container ENTRYPOINT / console scripts) that a package conversion can break — flagged in those slices' step-0 tasks; mirror scripts/select_tests/'s __main__.py.
