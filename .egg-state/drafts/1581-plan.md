# Plan: Gate phase completion on BRC consensus in clean-exit path

## Summary

The no-failures branch of the all-containers-exited path (step 5) in `_run_concurrent_phase` returns success without checking `consensus.is_complete`. The fix adds a final consensus recheck — mirroring the existing pattern in the `has_failures` branch — so that clean container exits without confirmed consensus are treated as failures. This applies to all BRC-enabled phases.

**Risks / edge cases**: If agents legitimately exit code 0 after a consensus timeout that was handled by the BRC tracker, this change would correctly block advancement. The NACK check (line 5274) remains in place and runs before the new consensus check, preserving existing escalation behavior.

## Implementation

### Phase 1: Implement

Add a consensus completeness check in the no-failures exit path of `_run_concurrent_phase`, and add tests.

**Tasks**:
1. **[task-1-1]** In `orchestrator/routes/pipelines.py`, in the no-failures branch of step 5 (after the NACK check at line 5295, before the `return 0` at line 5297), add a final consensus recheck using `executor.check_consensus()`. If `is_complete` is False, log a warning and return 1 (failure) instead of 0. Mirror the pattern used in the `has_failures` branch (lines 5219-5268). Acceptance: `_run_concurrent_phase` returns 1 when all containers exit code 0 but consensus is not complete.
2. **[task-1-2]** In `orchestrator/tests/test_consensus_race_on_exit.py`, add a test class `TestCleanExitWithoutConsensus` with a test for the scenario: all containers exit code 0, no failures, no NACKs, but `check_consensus()` always returns `is_complete=False` — assert `_run_concurrent_phase` returns exit code 1. Use the existing `_base_mocks` and `_CALL_ARGS` helpers. Acceptance: test passes and validates exit code 1.
3. **[task-1-3]** In the same test file/class, add a positive test: all containers exit code 0, no failures, and final consensus recheck returns `is_complete=True` — assert exit code 0. Acceptance: test passes and validates exit code 0.
