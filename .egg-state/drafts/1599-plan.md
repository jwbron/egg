# Plan: BRC history safety net + draft cleanup in PR phase

## Summary

Add two safety-net steps to the PR phase path in `pipelines.py`: (1) re-write BRC history files for all completed phases before PR creation, ensuring they're on the branch even if per-phase pushes failed; (2) `git rm` pipeline-specific draft files from `.egg-state/drafts/` to keep PR diffs focused on code changes. Both steps happen before the pre-PR push.

**Risks / edge cases**: `_write_brc_history` is idempotent (overwrites existing files), so re-writing is safe. Draft cleanup must be scoped to the current pipeline's identifier to avoid removing other pipelines' files. Must handle files that are already missing or untracked gracefully.

## Implementation

### Phase 1: Implement

Add BRC history re-write and draft cleanup to the PR phase path.

**Tasks**:
1. **[task-1-1]** In `orchestrator/routes/pipelines.py`, replace the comment at line 7426 ("BRC history files are written per-phase...") with a loop that calls `_write_brc_history()` for each phase in `pipeline.phases` that has status `COMPLETE`. Uses existing `_pipeline_identifier` helper. Then call `_commit_statefiles_to_worktree()` to commit the BRC history files. Acceptance: BRC history files for all completed phases exist in `.egg-state/brc-history/` after the PR phase runs.
2. **[task-1-2]** In `orchestrator/routes/pipelines.py`, add a `_cleanup_drafts_for_pr()` function near `_cleanup_stale_generic_drafts()` (~line 2209). It takes `worktree_path` and `pipeline_identifier`, finds pipeline-scoped draft files (`{id}-analysis.md`, `{id}-plan.md`, and any `{id}-*.md` in `.egg-state/drafts/`), runs `git rm -f --ignore-unmatch` on each, and commits the removal. Follows the same pattern as `_cleanup_stale_generic_drafts()`. Acceptance: function removes only pipeline-scoped draft files and commits the removal.
3. **[task-1-3]** In `orchestrator/routes/pipelines.py`, call `_cleanup_drafts_for_pr()` in the PR phase path after the BRC history write and before the pre-PR push (~line 7429). Pass `worktree_repo_path` and the pipeline identifier. Acceptance: draft files are removed before PR creation.
4. **[task-1-4]** Add tests: (a) BRC history re-write in PR phase covers all completed phases, (b) `_cleanup_drafts_for_pr` removes pipeline-scoped drafts and commits, (c) `_cleanup_drafts_for_pr` is a no-op when no drafts exist, (d) `_cleanup_drafts_for_pr` doesn't remove other pipelines' drafts. Acceptance: all tests pass.
