# Plan: Exclude base-branch commits from re-review deltas

## Summary

Re-review prompts use `git diff ${LAST_REVIEW_COMMIT}..HEAD` — a two-dot snapshot diff that wrongly includes any base-branch merge that landed between the last review and HEAD. Switch all five affected call sites to `git log ${LAST_REVIEW_COMMIT}..HEAD --not origin/${BASE_REF} -p`, which explicitly excludes commits reachable from the base branch. Three GHA shell scripts accept a new `BASE_REF` env var (default `main`); `reusable-review.yml` plumbs the real base ref from its existing `pr-meta` step. Cycle-1 full-PR reviews (three-dot `git diff origin/{base}...HEAD`) are untouched.

Approach rationale: Option A (per-commit patch series with `--not origin/<base>`) beats Option B (reconstructing PR-side trees) on simplicity and correctness; three-dot alone doesn't work because `merge-base(LAST_REVIEW_COMMIT, HEAD) = LAST_REVIEW_COMMIT`.

**Risks / edge cases**: GHA PR-code checkouts are shallow — updated prompts must `git fetch origin ${BASE_REF}` before the log command. Orchestrator worktrees already maintain `origin/<base>` (cycle-1 relies on it today). Output format shifts from aggregated diff to per-commit patch series — LLM reviewers handle both. `BASE_REF` defaults to `main` for backward compat. Non-default bases are plumbed internally in `reusable-review.yml` — no consumer-workflow edits needed.

## Implementation

### Phase 1: Implement

Five file-classes, six mechanical tasks. Cycle-1 full-PR review paths are untouched throughout.

**Tasks**:

1. **[task-1-1]** In `orchestrator/routes/pipelines.py` `_build_review_prompt()` (~L3297), replace the `is_delta_review` branch of `diff_command` with `git log {last_reviewed_commit}..HEAD --not {_base_ref} -p`. Leave the cycle-1 three-dot `git diff {_base_ref}...HEAD` branch unchanged. Acceptance: cycle > 1 with `last_reviewed_commit` set emits the new command form; cycle 1 still emits three-dot.

2. **[task-1-2]** In `orchestrator/routes/pipelines.py` (~L3448), update the "Delta Review" directive text to reference the new `git log … --not {_base_ref} -p` command and add a `git fetch origin {base_branch}` nudge before it. Acceptance: Delta Review section names the new command and includes the fetch instruction.

3. **[task-1-3]** In each of `action/build-review-prompt.sh` (~L142), `action/build-agent-mode-design-review-prompt.sh` (~L92), and `action/build-contract-verification-prompt.sh` (~L106): accept `BASE_REF` env var (`local base_ref="${BASE_REF:-main}"`); replace the `git diff ${LAST_REVIEW_COMMIT}..HEAD` instruction with `git fetch origin ${base_ref}` followed by `git log ${LAST_REVIEW_COMMIT}..HEAD --not origin/${base_ref} -p`; document `BASE_REF` in the file header. Initial-review path untouched. Acceptance: all three scripts with `LAST_REVIEW_COMMIT=abc123 BASE_REF=main` produce prompts containing both new commands and no `git diff abc123..HEAD`.

4. **[task-1-4]** In `.github/workflows/reusable-review.yml`, extend the `pr-meta` step (~L344-365) to emit `base-ref` from the existing `pr_json` jq pipeline (`echo "base-ref=$(echo "$pr_json" | jq -r '.base.ref')"`). Pass `BASE_REF: ${{ steps.pr-meta.outputs.base-ref }}` into the "Build review prompt from trusted main branch" step's `env:` block (~L487-494). No consumer-workflow changes. Acceptance: a workflow run sets `BASE_REF` to the PR's actual base branch when invoking prompt-build.

5. **[task-1-5]** Update `tests/action/test_build_review_prompt.py`, `tests/action/test_build_agent_mode_design_review_prompt.py`, `tests/action/test_build_contract_verification_prompt.py`: replace re-review assertions that check for `git diff <sha>..HEAD` with assertions for `git log <sha>..HEAD --not origin/main -p` and `git fetch origin main`; extend test helpers to accept a `base_ref` kwarg; add one test per file that passes `base_ref="develop"` and asserts `origin/develop` appears in the prompt. Initial-review tests unchanged. Acceptance: `pytest tests/action/` passes; no test still asserts `git diff <sha>..HEAD` on the re-review path.

6. **[task-1-6]** Update `orchestrator/tests/test_pipeline_prompts.py`: replace delta-branch `git diff <sha>..HEAD` assertions with `git log <sha>..HEAD --not origin/<base> -p`; assert Delta Review directive references the new command plus fetch nudge; add a test that calls `_build_review_prompt(..., review_cycle=2, last_reviewed_commit="<sha>", base_branch="develop", ...)` and asserts `origin/develop` appears. Cycle-1 assertions unchanged. Acceptance: `pytest orchestrator/tests/test_pipeline_prompts.py` passes; new non-default-base test fails if `base_branch` isn't threaded through.
