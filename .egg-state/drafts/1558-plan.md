# Plan: Remove DevserverManager and all Docker Compose deployment validation code

## Summary

Remove the DevserverManager component and all associated code. This is dead code removal — the feature was never used, and its Docker Compose runtime is being removed in #1553 (Kubernetes migration). The approach is straightforward: delete the core modules, their tests, and clean up all import/reference sites.

**Risks / edge cases**: None identified. All imports of `egg_contracts.deployment` and `teardown_devserver` are confined to devserver-related code. The `teardown_devserver()` calls in `phases.py` are no-ops when no devserver is active, so removing them has no behavioral impact.

## Implementation

### Phase 1: Implement

Remove all DevserverManager code, tests, constants, and references.

**Tasks**:
1. **[task-1-1]** Delete `orchestrator/devserver.py` and `orchestrator/tests/test_devserver.py`. Acceptance: Files no longer exist.
2. **[task-1-2]** Delete `orchestrator/routes/checks.py` and `orchestrator/tests/test_routes_checks.py`. Acceptance: Files no longer exist.
3. **[task-1-3]** In `orchestrator/api.py`, remove the `from routes.checks import checks_bp` / `from .routes.checks import checks_bp` import lines and both `app.register_blueprint(checks_bp)` lines. Acceptance: No references to `checks_bp` in `api.py`.
4. **[task-1-4]** In `orchestrator/routes/phases.py`, remove the `from routes.checks import teardown_devserver` import (line 81) and all 3 `teardown_devserver(pipeline_id)` call sites (lines 335, 481, 557) along with their associated comments. Acceptance: No references to `teardown_devserver` in `phases.py`.
5. **[task-1-5]** In `shared/egg_config/constants.py`, remove `EGG_CHECK_NETWORK_PREFIX`, `DEVSERVER_CPU_LIMIT`, `DEVSERVER_MEMORY_LIMIT`, `DEVSERVER_PIDS_LIMIT`, `DEVSERVER_HARD_TIMEOUT_SECONDS` constant definitions and their entries in the `__all__` list. Acceptance: No `DEVSERVER_*` or `EGG_CHECK_NETWORK` references in constants.py.
6. **[task-1-6]** Delete `shared/egg_contracts/deployment.py` and `tests/shared/egg_contracts/test_deployment_config.py`. Acceptance: Files no longer exist.
7. **[task-1-7]** Delete the `integration_tests/deployment_validation/` directory (contains `test_deployment_check_e2e.py` and `__init__.py`). Acceptance: Directory no longer exists.
