# Plan: Clean up stale generic drafts and add diagnostic logging

## Summary

Fix stale generic draft files (`analysis.md`, `plan.md`) persisting on work branches by removing them at pipeline start, and add diagnostic logging to `_read_phase_draft` so transient draft-not-found failures leave a trace for debugging.

**Risks / edge cases**: Cleanup must only target the exact unprefixed filenames (`analysis.md`, `plan.md`) in `.egg-state/drafts/` — not any prefixed files.

## Implementation

### Phase 1: Implement

**Tasks**:
1. **[task-1-1]** In `orchestrator/routes/pipelines.py`, add `_cleanup_stale_generic_drafts(worktree_path)` that removes `.egg-state/drafts/analysis.md` and `.egg-state/drafts/plan.md`. **CRITICAL**: Use `git rm -f` to stage the deletions and then `git commit` directly inside the cleanup function — do NOT use `_commit_statefiles_to_worktree` because that function only stages files matching `{pid}.*` or `{pid}-*` patterns and will silently skip unprefixed file deletions. Fall back to `os.unlink` if the file is untracked. Call after `_sync_worktree_with_remote` at ~line 5934, then push via `spawner.gateway.push_worktree_branch`.
2. **[task-1-2]** In `orchestrator/routes/pipelines.py:_read_phase_draft()`, add `logger.debug` when `draft_path.exists()` returns False, logging the attempted path, phase, issue_number, and pipeline_id.
3. **[task-1-3]** In `orchestrator/tests/test_read_phase_draft.py`, add tests: (a) `_cleanup_stale_generic_drafts` removes `analysis.md` and `plan.md` but leaves prefixed files intact, (b) no-op when no drafts directory exists, (c) `_read_phase_draft` emits a debug log when the draft file is missing.
