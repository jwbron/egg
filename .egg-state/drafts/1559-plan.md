# Plan: Clean up stale generic drafts and add diagnostic logging

## Summary

Fix stale generic draft files (`analysis.md`, `plan.md`) persisting on work branches by removing them at pipeline start, and add diagnostic logging to `_read_phase_draft` so transient draft-not-found failures leave a trace for debugging. The root cause is that legacy unprefixed draft files from prior pipelines accumulate on work branches and are never cleaned up, while the draft-read function silently returns `None` with no logging when files are missing.

**Risks / edge cases**: Cleanup must only target the exact unprefixed filenames (`analysis.md`, `plan.md`) in `.egg-state/drafts/` — not any prefixed files. The cleanup runs after worktree sync but before agent containers spawn, so there's no race. If the worktree path doesn't exist or has no drafts directory, the cleanup is a no-op.

## Implementation

### Phase 1: Implement

Clean up stale generic drafts at pipeline start and add debug logging to draft reads.

**Tasks**:
1. **[task-1-1]** In `orchestrator/routes/pipelines.py`, add a `_cleanup_stale_generic_drafts(worktree_path: Path)` function that removes `.egg-state/drafts/analysis.md` and `.egg-state/drafts/plan.md` (unprefixed generic files only). Call it after `_sync_worktree_with_remote` at ~line 5934 (inside the `if worktree_repo_path != repo_path:` block), then commit the removal via `_commit_statefiles_to_worktree`. Acceptance: When a pipeline starts on a branch with stale `.egg-state/drafts/analysis.md`, the generic file is removed before agents run; prefixed files like `1553-analysis.md` are untouched.
2. **[task-1-2]** In `orchestrator/routes/pipelines.py:_read_phase_draft()` (~line 1619), add a `logger.debug` call when `draft_path.exists()` returns False, logging the attempted path (`str(draft_path)`), phase, issue_number, and pipeline_id. This makes transient failures diagnosable without being noisy. Acceptance: When `_read_phase_draft` can't find a draft, the debug log includes the full attempted path.
3. **[task-1-3]** In `orchestrator/tests/test_read_phase_draft.py`, add tests: (a) test that `_cleanup_stale_generic_drafts` removes `analysis.md` and `plan.md` but leaves prefixed files intact, (b) test that `_cleanup_stale_generic_drafts` is a no-op when no drafts directory exists, (c) test that `_read_phase_draft` emits a debug log when the draft file is missing (use `caplog` or mock the logger). Acceptance: All new tests pass and cover the cleanup and logging behavior.
