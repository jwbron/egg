# Plan — Full-context backstop for BRC event-pump agents (Issue #3200)

## HITL Decisions
- **cq-1 (scope):** Option A — Full scope: all 3 components + restart-memory preservation fix.

## Architecture Overview

The plan delivers four sequential slices, each building on prior slices:

```
Slice 1: Restart-memory preservation      ← prerequisite fix
Slice 2: Session resume (warm path)        ← #3186
Slice 3: Deterministic seed layer composer  ← #3189
Slice 4: Enrichment layer injection        ← #3188
```

Each slice is independently shippable. The ordering ensures the foundation (restart fix) ships before the resume path depends on artifact survival, and the deterministic layer ships before the enrichment layer is composed on top of it.
