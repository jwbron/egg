PROVENANCE
----------
The slice-1 spike's BRC artifact landed under coder allowlist.  The
spike script (`2908_event_pump_prototype.sh`) is throwaway, and the

PIPELINE STATUS SNAPSHOT
------------------------
Captured at end of the smoke trace via the prototype's
`is_consensus_complete()` helper, which calls
`egg-orch consensus status --json`.  Output (post-iter-3):

    {"is_complete": true, "agents": {}}

is_complete=true is the signal the prototype's main loop reads to exit
0.  Production k3s output adds the per-role agent matrix (producer
phase, reviewer phase, confirmed status); the smoke trace's empty
agents map reflects the mock harness, not the production behaviour.
